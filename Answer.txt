If we had one hundred heroes in the program and only Arthur took damage, there would still be just one Hero class box because the class is a single blueprint shared by all heroes. However, there would be one hundred separate Hero object boxes, each representing a different hero stored in memory. Arthur’s object box would show his HP reduced to 90, while the other ninety-nine heroes would remain at their original HP values. This shows that the class is shared, but each object keeps its own independent data.
